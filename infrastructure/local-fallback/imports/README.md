# CSV Imports

Pon aqui archivos CSV exportados desde Supabase antes de copiarlos a Ubuntu.

No se versionan CSV reales porque pueden contener datos personales.

Nombres sugeridos:

- `auth_users.csv`: usuarios de Supabase Auth.
- `profiles.csv`: tabla `public.profiles`.
- `profile_login_emails.csv`: correos secundarios o aliases, si existe.
