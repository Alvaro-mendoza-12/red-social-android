# Paquete de proyecto — NOVVIN
Incluye investigación de mercado, prompt maestro, PRD de Live/Live Play y matriz de aceptación.

## Archivos
- `PROMPT_MAESTRO_NOVVIN.md`: instrucciones principales para el agente.
- `PROMPT_MAESTRO_NOVVIN.docx`: versión editable del prompt.
- `INVESTIGACION_MERCADO_BENCHMARK.md`: benchmark público.
- `PRD_NOVVIN_LIVE_LIVE_PLAY.md`: especificación de directos, regalos y juegos.
- `MATRIZ_ACEPTACION_QA.md`: pruebas críticas.
- `FUENTES_Y_REFERENCIAS.md`: URLs consultadas.

## Uso recomendado
1. Adjunta el paquete a Astra/Codex/Antigravity.
2. Envía el mensaje de arranque incluido al final del prompt maestro.
3. Exige primero inventario y diagnóstico; no permitas cambios destructivos al inicio.
4. Revisa el plan por fases antes de aprobar modificaciones de riesgo.
5. Exige evidencias y pruebas para cada función.

El benchmark es cualitativo y público. No es auditoría del código privado, estudio cuantitativo de mercado ni garantía de que cada función anunciada esté implementada.
