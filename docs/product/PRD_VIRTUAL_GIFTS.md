# Regalos virtuales

El catálogo identifica el regalo, precio y recurso visual. Antes de confirmar, el usuario debe conocer destinatario y coste. La API establece el importe autorizado, registra con una clave idempotente y emite el recibo. La animación puede reanudarse o degradarse a una imagen sin repetir el débito. Los puntos de un canal, el saldo de compra y la cantidad retirable tienen usos distintos.

La suite local cubre casos del libro de movimientos y reintentos con datos sintéticos. Para habilitar dinero real faltan conciliación de reversos con el proveedor, límites y elegibilidad revisados, recuperación ante interrupción y verificación por dispositivo del coste de representación de efectos. La compra, el retiro y el reparto real no se ejercitaron en esta revisión. [Riesgos](../risks/RISK_REGISTER.md)
