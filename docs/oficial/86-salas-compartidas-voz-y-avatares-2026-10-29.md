# 86 — Salas compartidas, recuperación de voz y avatares

Fecha: 2026-10-29, Bogotá. Continuación de la auditoría 85. El propietario priorizó esta vez la web y autorizó publicar sus cambios, conservando el mismo código en `main` y `feature/live-gifts`.

## Cambios

- La voz web inicia por HTTP polling, con WebSocket como alternativa si polling falla. Evita convertir una sesión HTTP sana en una conexión del relé WebSocket con duración máxima de 300 segundos. Se mantiene el audio WebRTC; polling sólo transporta señalización. La admisión tiene plazo de diez segundos, reintento de membresía, reconexión ante desconexión explícita del servidor y botón manual de recuperación. La configuración TURN fallida conserva el fallback STUN existente.
- El recorrido autenticado de producción reprodujo además la causa concreta del aviso: `VITE_SIGNALING_URL` usa `https://conectate.tail9b267c.ts.net:8443`, mientras la conversión a origen público sólo reconocía HTTPS sin puerto. Chromium bloqueaba TURN/polling/WebSocket por acceso a red local. Se reconoce exclusivamente ese mismo servidor y el puerto 8443 conocido, conservando las rutas y el proxy público fijo. Otros hosts, puertos y URLs con credenciales siguen sin convertirse. La prueba de regresión cubre la configuración real; no se pide permiso de red local al visitante.
- La carga inicial reutiliza los participantes de la respuesta del detalle; evita peticiones simultáneas repetidas y consultas de salas ocultas. Una sala visible y sincronizada consulta cada quince segundos; durante recuperación conserva cinco segundos. La carga muestra un indicador visible y tiene plazo de doce segundos.
- Web y Android comparten enlaces oficiales `https://red-social-android.vercel.app/voice/{id}`. Las acciones permiten copiar o abrir el selector de compartir, sin enviar mensajes automáticamente. El enlace no incluye contraseña, token ni datos privados de la sala.
- En escritorio, la invitación llega a la sala web. En Android, la página intenta abrir el paquete `conectate.com` mediante un Intent y ofrece «Abrir en la app» y «Continuar en la web». Si el navegador admite el Intent y la app no está instalada, usa la dirección web de fallback. Los navegadores integrados pueden requerir la acción explícita del visitante; no se afirma que el sitio pueda detectar universalmente la instalación.
- Login, registro y recuperación de contraseña conservan el destino validado. Se rechazan redirecciones externas. Las salas públicas y las privadas del propietario entran desde el enlace; los demás invitados de una sala privada deben introducir su contraseña. Compartir no elude la autorización del servidor.
- Android interpreta el enlace HTTPS oficial y `conectate://voice/{id}`. Guarda el identificador en el estado del grafo de navegación durante login/registro y lo consume una sola vez al completar el acceso. Abre el detalle de la sala y conserva sus controles de entrada y permisos de micrófono.
- Los avatares web reciben ahora el fallo definitivo del origen protegido o del service worker incluso cuando no se llegó a asignar un `src`. Muestran las iniciales y permiten los reintentos existentes al volver la red/controlador, con aislamiento por identidad. La captura recibida mostraba imágenes rotas; no evidencia rotación.

Android aprobó 1.956 pruebas unitarias en 414 suites, cero fallos, errores u omisiones. APK QA y APK de instrumentación generados; lint completo: cero errores y 320 advertencias. No se dispone de la huella SHA-256 del certificado **de firma de Play**. El valor recibido no tenía el formato de 64 dígitos hexadecimales. No se publica un `assetlinks.json` inventado ni se da por validada la asociación HTTPS. El botón explícito usa el esquema de la aplicación y no sustituye esta verificación. No se publica un nuevo AAB en Play en esta ejecución.

La comparación anterior **82,3 → 8,6 ms** mide una consulta de base de datos en la copia aislada, no el recorrido aplicación–servidor. La optimización API de la revisión 85 continúa sin desplegar; publicar la web no la instala en Ubuntu. La API de producción no se sustituye en esta tanda.

El propietario confirmó que sólo hay emulador. No se certifican audio entre redes, llamadas/LIVE entre teléfonos, notificaciones con el dispositivo bloqueado ni capacidad masiva. El candidato Android conserva 9.1.30 / 170 y requiere su propio artefacto firmado y distribución.
