# Referencias externas usadas

Consultadas el 2026-09-26. Son criterios para revisar y priorizar, no prueba de certificación ni de cumplimiento del producto.

| Fuente primaria | Aplicación a esta auditoría |
|---|---|
| [OWASP API Security Top 10 2023 — Broken Object Level Authorization](https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/) | Revisar propiedad/autorización por objeto en mensajes, media, videos, LIVE y pagos. |
| [OWASP API Security Top 10 2023 — Broken Function Level Authorization](https://api-security.owasp.org/editions/2023/en/0xa5-broken-function-level-authorization/) | Matriz de capacidades para administración y operaciones sensibles. |
| [OWASP MASVS](https://mas.owasp.org/MASVS/) | Estructurar revisión de almacenamiento, criptografía, autenticación, red y plataforma Android. |
| [WCAG 2.2, W3C](https://www.w3.org/TR/wcag/) | Contraste, navegación, foco, tamaños, estados y mensajes de error en web y patrones extrapolables a UI móvil. |
| [Android Developers — accesibilidad y objetivos táctiles](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views) | Comprobar controles táctiles de al menos 48 dp y etiquetas apropiadas. |
| [NIST SP 800-218, Secure Software Development Framework](https://csrc.nist.gov/pubs/sp/800/218/final) | Controles reproducibles de desarrollo, dependencias, pruebas y respuesta a fallos. |
| [ISO/IEC 25010:2023](https://committee.iso.org/standard/78176.html) | Agrupar calidad funcional, rendimiento, seguridad, mantenibilidad y portabilidad. |
| [Nodemailer CHANGELOG](https://github.com/nodemailer/nodemailer/blob/master/CHANGELOG.md) y [política de seguridad](https://github.com/nodemailer/nodemailer/security) | Verificar cambio mayor a v10, requisito Node 20 y línea de soporte. |
| [PyYAML en PyPI](https://pypi.org/project/PyYAML/) | Versión, compatibilidad y origen de dependencia Python fijada para CI. |
| [Google Play — propiedad intelectual](https://support.google.com/googleplay/android-developer/answer/9888072?hl=en) | Revisar evidencia de derechos sobre imágenes de juegos, música, glifos y marketing. |
| [Google Play — contenido generado por usuarios](https://support.google.com/googleplay/android-developer/answer/9876937?hl=en-GB) | Revisar términos, reporte, bloqueo y moderación de música, videos y LIVE. |
| [GitHub Actions — sintaxis de workflows](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax) | Verificar uso de matriz y `working-directory` por paso en el nuevo CI de servicios. |

Las mediciones del sistema y los hallazgos se sustentan en código, pruebas y reportes locales, no en estas fuentes normativas por sí solas.
